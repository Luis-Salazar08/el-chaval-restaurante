# El Chaval - Restaurant Web System 🍽️

Proyecto final del curso de Desarrollo Web FullStack (Semanas 1 a 11).

## Descripción
Sistema web desarrollado bajo un enfoque **Mobile-First** para la gestión del restaurante "El Chaval". 

Cuenta con dos apartados principales:
* **Vista de Usuario (Pública):** Interfaz optimizada para celulares donde los clientes pueden visualizar el menú del día y enviar sugerencias.
* **Dashboard Administrativo:** Panel privado y seguro para que el personal gestione pedidos (mesa/delivery), actualice los platos disponibles y lea el buzón de sugerencias.
